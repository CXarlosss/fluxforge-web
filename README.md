# FluxForge Web

> Constructor visual de workflows con ejecución en tiempo real y debugging animado.

## ✨ Features

- **Canvas Interactivo:** ReactFlow con nodos personalizados (Trigger, HTTP, Code, Log)
- **Animaciones de Flujo:** Edges animadas con datos reales via WebSocket
- **Sandbox de Código:** Monaco Editor + ejecución segura via QuickJS
- **Exportación n8n:** Migración sin fricción a infraestructura productiva

## 🎨 Stack

React 18 · TypeScript · Vite · ReactFlow · Zustand · Framer Motion · Monaco Editor · TailwindCSS

## 🚀 Deploy

```bash
npm install
npm run dev
```

## 🔗 API
Conecta a fluxforge-api via WebSocket en `/ws` y REST en `/api`.
